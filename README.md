# Student-Attendance-Management-System

## 📌 Project Overview

The **Student Attendance Management System** is a web-based application designed to simplify and manage student attendance digitally. It helps manage student records, record attendance, and maintain attendance details in an organized way. The system reduces manual work and makes attendance tracking easier for educational institutions.

## 🎯 Objectives

- Maintain student information in an organized manner.
- Record and manage student attendance digitally.
- Reduce manual attendance-recording work.
- Make attendance information easier to access and manage.
- Improve the efficiency of attendance management.

## ✨ Features

- **Student Management:** Manage student information.
- **Attendance Management:** Record and maintain attendance details.
- **Database Management:** Store and retrieve application data.
- **User-Friendly Interface:** Simple interface for interacting with the system.
- **Organized Records:** Maintain student and attendance information systematically.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MySQL
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Install the following before running the application:

- Python
- MySQL Server
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/abhiramreddy-07/Student-Attendance-Management-System.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Student-Attendance-Management-System
   ```

3. Navigate to the application folder:

   ```bash
   cd sams
   ```

4. Install the required Python packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Configure the database and environment variables according to the project configuration.

6. Set up the database using the project's database setup instructions.

7. Start the application using the appropriate command specified in the project configuration.
